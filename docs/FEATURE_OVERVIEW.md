# LTT BD — Product Overview

**Product:** LTT BD — Smart Group Tracking, Tourist Safety & Emergency Assistance Platform

**Purpose:** Keep tour participants connected, help organizers account for everyone, and make it fast to request and coordinate assistance.

## Core experiences
1. Tourist PWA: join trip, consent to location sharing, view authorized group members, navigate, see itinerary and request assistance.
2. Tour Manager workspace: monitor assigned trips, run headcounts, coordinate meeting points, receive and assign help requests.
3. Super Admin dashboard: manage trips, users, organizers, permissions, configuration, reports and audit logs.

## Non-negotiable principles
- Location is shared only after clear, informed consent.
- Location visibility is limited to the active trip and authorized roles.
- Tourists can see whether sharing is active, paused, stale or unavailable.
- Emergency requests are recorded with delivery/acknowledgement states; do not falsely claim an alert was delivered.
- Provide clear retention and deletion policies.
- Apply Row Level Security to every relevant Supabase table.
- Make mobile use exceptionally simple and accessible.
