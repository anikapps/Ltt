# LTT BD — Brand Identity

## Brand expression

**Brand name:** LTT BD  
**Product purpose:** Group travel coordination, live location sharing, passenger onboarding, trip communication and traveller assistance.  
**Brand line:** Group travel, in sync.

The initials are kept as supplied. No expanded form is assumed.

## Visual system

- **Primary navy:** `#0D1832` — trust, clarity and operational focus.
- **Primary blue:** `#2450D2` — primary actions, links and the LTT BD signature mark.
- **Bright blue:** `#4778FF` — highlights and active states.
- **Mint accent:** `#8EF0D4` — route endpoints, positive states and subtle accents.
- **Background:** `#F5F7FB` — clean, low-glare application surfaces.

## Logo use

The application uses a custom route-inspired LTT BD mark with a typographic wordmark. It is provided as a React component (`src/components/BrandIdentity.tsx`) and as scalable SVG app icons (`public/icons/`). The light variant is intended for dark/navy surfaces; the default variant is for white and light surfaces.

## Interface principles

- Keep the brand visible but secondary to trip information and safety actions.
- Maintain high contrast and clear focus indicators.
- Use the same wordmark, colour system and iconography across landing, join, traveller and operations screens.
- Treat passenger identifiers and live location as private information; never use branding as a substitute for consent or access control.
