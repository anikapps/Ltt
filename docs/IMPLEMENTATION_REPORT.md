# LTT BD — Final Implementation Report

## 1. Completed Modules & Features

| Module | Implementation Details |
|---|---|
| **1. Role-Based Access Control (RBAC)** | Implemented `super_admin`, `trip_organizer`, `tour_manager`, `responder`, and `tourist` roles across `supabase/schema.sql` (Row Level Security policies + `organizer_assignments`) and server API routes. |
| **2. Frictionless Tourist Onboarding (`/join/[token]`)** | Supports joining via unique Trip URL (`/join/malaysia-tour-2026-invite`) or short Invitation Code (`KL2026`), captures Full Name, Preferred Display Name, Mobile Number OR Passport Number, Subgroup (`Bus A` / `Bus B`), and Emergency Contact, displays the Organizer Fallback Contact and Privacy/Retention Notice, and assigns a unique internal Tourist ID (`LTT-001`). |
| **3. Consent-Based Live Location Tracking** | Explicit, revocable location consent checkbox and persistent header status toggle (`Sharing Active`, `Paused`, `Permission Denied`, `Stale`, `Offline`). Rejects invalid coordinates outside `[-90..90] / [-180..180]`, displays last-updated time and GPS accuracy (`±m`), and marks coordinates stale after configurable `stale_threshold_seconds` (default 180s). |
| **4. Interactive Group Map & Geofences (`GroupMap.tsx`)** | Built with Leaflet (`reactStrictMode: false` for rock-solid Windows rendering) using CARTO Voyager tiles (`NEXT_PUBLIC_MAP_TILE_URL`). Displays tourist initials/status pins, marker clustering for 25–100 tourists, ★ Meeting Point markers, dashed Geofence radius circles, route polyline preview, and a `My Location` recenter button. |
| **5. Google Maps Navigation Handoff** | Tapping any tourist pin or Meeting Point opens a confirmation modal displaying straight-line distance and hands off destination coordinates to Google Maps (`https://www.google.com/maps/dir/?api=1&origin=...&destination=...&travelmode=walking`). |
| **6. 7-Category SOS & Assistance Centre** | Supports all 7 categories (`Lost / separated from group`, `Medical assistance`, `Accident / injury`, `Transport assistance`, `Safety / security concern`, `Cannot find meeting point`, `Other`), priorities (`Normal`, `High`, `Critical`), truthful server acknowledgement state (`serverAcknowledged: true`), tourist cancellation window, responder assignment, internal staff-only notes, two-way trip-scoped chat thread, and resolution outcome notes. |
| **7. Smart Group Coordination** | **Digital Headcount Roll Calls** (tourists confirm `I Am Present & Safe` or `Need Assistance`; organizers see Present, Pending, and Help counts), **Scheduled Meeting Points & Geofences**, **Possible Separation Detection** (flags tourists `>500m` from the active meeting point), **Trip Announcements** with read receipts, **Daily Itinerary**, **Offline Essentials Cache** (`localStorage`), and a **Privacy-Safe Digital Tourist QR ID Card**. |
| **8. Admin Command Centre (`/admin/trips/[tripId]`)** | 6-tab desktop command centre with KPI strip, Live Map & Geofences, Incident Inbox, Searchable Tourist Directory, Safe CSV Export (excludes passport numbers by default), Excel/CSV Roster Import with row-level error reporting, Staff Assignment, Configurable Thresholds/Retention Settings, and one-click **End Trip & Purge Personal Data**. |

## 2. Known Platform & Mobile Browser Limitations

1. **Mobile Browser Background GPS Tracking:** Standard mobile web browsers (iOS Safari and Android Chrome) suspend JavaScript timers when the browser tab is closed, backgrounded for extended periods, or when the phone screen is locked. LTT BD displays the honest last-updated timestamp and automatically marks locations **Stale / Offline** after the configured threshold rather than faking background positions.
2. **External Notification Channels (SMS / WhatsApp / Email / Push):** In-app realtime alerts and direct `tel:` fallback calling work out of the box. External SMS, WhatsApp Business API, or email delivery require external paid provider credentials and are never falsely claimed as delivered unless configured.
3. **Turn-by-Turn Routing:** LTT BD previews the direct vector line and distance inside the app and hands off turn-by-turn street navigation to **Google Maps** upon user confirmation.

## 3. Exact Windows Startup & Deployment Steps

### Local Windows Startup
1. Extract `LTT-BD-Project.zip`.
2. Double-click **`start-ltt-bd.bat`** (which automatically runs `cd /d "%~dp0"`, installs dependencies with network-drop retry flags if `node_modules\.bin\next` is missing, runs the 14-point acceptance test suite, starts the server, and opens `http://localhost:3000` once port 3000 is listening).
3. Sign in to `/admin` with the private local credentials generated by `scripts/bootstrap-local-env.mjs`, or test the tourist join link at `/join/malaysia-tour-2026-invite` (or short code `KL2026`).

### Cloud Deployment (Supabase + Vercel / Cloudflare)
1. Run `supabase/schema.sql` in your Supabase SQL Editor.
2. Set `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `LTTBD_ROSTER_PEPPER`, and `LTTBD_SESSION_SECRET` in your hosting environment variables (`.env.example`).
3. Deploy via Vercel (`vercel deploy`) or Cloudflare Workers.
